cartolex - instalação no seu computador
=======================================

O cartolex mapeia um campo de pesquisa a partir dos textos das pessoas que
trabalham nele. Esta pasta faz a instalação para você, sem direitos de
administrador. O instalador baixa cerca de 1 GB (o cartolex, as bibliotecas de
que ele precisa e os modelos de língua para inglês, francês e português),
então use uma boa conexão. Leva alguns minutos.

Textos em espanhol, alemão ou italiano precisam cada um do seu modelo de
língua, cerca de 45 MB cada. No final, o instalador pergunta quais adicionar e
mostra a licença de cada modelo antes de baixá-lo (o do espanhol é GNU GPL, o
do italiano só para uso não comercial). Você pode adicioná-los depois com o
comando que ele mostra.

Tudo fica em uma única pasta dentro da sua pasta pessoal, chamada
"cartolex": o programa, o Python dele, os downloads e o registro da
instalação (install.log). Seus projetos ficam em outro lugar, onde você
escolher criá-los.

Para atualizar o cartolex, baixe o kit mais recente e execute o instalador
dele: ele atualiza a instalação no mesmo lugar. Seus projetos não são
alterados.


macOS
-----

1. Clique duas vezes no arquivo zip para descompactá-lo e abra a pasta.
2. Clique duas vezes em "Install cartolex.command". Se a instalação começar
   numa janela do Terminal, tudo certo: siga para o passo 3.

   Se o macOS disser que o arquivo "está danificado e não pode ser aberto"
   (ou que não pode verificar o desenvolvedor), o arquivo não está danificado:
   o macOS põe em quarentena tudo o que sai de um arquivo baixado. Botão
   direito > Abrir NÃO resolve essa mensagem, e desde o macOS 15 não funciona
   mais. Faça assim, uma única vez; funciona sempre:

     a. Abra o Terminal: Cmd + Espaço, digite Terminal, depois Enter.
     b. Na janela do Terminal, digite  sh  seguido de UM ESPAÇO. Ainda não
        pressione Enter.
     c. No Finder, arraste o arquivo "Install cartolex.command" para a janela
        do Terminal: o caminho se escreve sozinho.
     d. Pressione Enter.

   Nenhum caminho para digitar. O instalador retira a quarentena da pasta no
   caminho: você não precisará fazer isso de novo.
3. A janela do Terminal mostra o andamento. Quando aparecer "Done", pressione
   Enter.
4. Um arquivo "cartolex.command" está agora na sua mesa. Clique duas vezes
   nele para abrir o cartolex no navegador. Deixe a janela do Terminal aberta
   enquanto trabalha; feche-a para encerrar o cartolex.


Windows
-------

A versão 1.0.0 ainda não funciona no Windows; uma próxima versão 1.0
funcionará.

1. Clique com o botão direito no arquivo zip, escolha "Extrair Tudo..." e
   abra a pasta. (Executar o instalador de dentro do zip, sem extrair, não
   funciona.)
2. Clique duas vezes em "Install cartolex.bat". O Windows pode mostrar "O
   Windows protegeu o computador": clique em "Mais informações" e depois em
   "Executar assim mesmo".
3. Uma janela mostra o andamento. Quando aparecer "Done", pressione uma tecla
   para fechá-la.
4. Um atalho "cartolex" está agora na área de trabalho e no menu Iniciar. Ele
   abre o cartolex no navegador. Deixe a janela preta aberta enquanto
   trabalha; feche-a para encerrar o cartolex.

Se a página ficar vazia ou aparecer desorganizada no Microsoft Edge (em
computadores gerenciados, o Edge às vezes muda para o "modo Internet
Explorer" para endereços locais), copie o endereço mostrado na janela preta
para o Google Chrome ou o Firefox.

Se o instalador disser que não há Python neste computador: instale o Python
a partir de https://www.python.org/downloads/ (marque "Add python.exe to
PATH" na primeira tela) e execute "Install cartolex.bat" de novo.


Linux
-----

1. Descompacte o arquivo zip e abra um terminal na pasta.
2. Torne o instalador executável e execute-o:
       chmod +x install-cartolex.sh
       ./install-cartolex.sh
3. O cartolex está agora no menu de aplicativos (e na área de trabalho, se
   ela mostrar arquivos). Ele abre o cartolex no navegador. Você também pode
   executar ~/cartolex/env/bin/cartolex em um terminal.

No Debian ou Ubuntu, se o instalador pedir: sudo apt install python3-venv


Quando a rede bloqueia o instalador
-----------------------------------

O instalador tenta três caminhos, um depois do outro: com o uv (um
instalador de Python que ele baixa de astral.sh), depois com o uv confiando
nos certificados do seu computador (o que resolve a maioria das redes que
inspecionam conexões seguras), depois com o Python já instalado no seu
computador. O registro diz qual caminho funcionou e por que os outros não.

Se os três falharem:
- Atrás de um proxy, informe-o antes de executar o instalador. Em um
  terminal (macOS, Linux): export HTTPS_PROXY=http://proxy.example.org:8080
  e execute o instalador nesse terminal. No Windows, em um prompt de
  comando: set HTTPS_PROXY=http://proxy.example.org:8080
  e execute "Install cartolex.bat" nesse prompt. Peça o endereço do proxy
  ao seu serviço de informática.
- Instale o Python 3.10 ou mais recente a partir de
  https://www.python.org/downloads/ e execute o instalador de novo: esse
  caminho não precisa do uv nem de astral.sh.
- Peça ao seu serviço de informática para liberar estes endereços: pypi.org,
  files.pythonhosted.org (os pacotes Python), github.com e
  objects.githubusercontent.com (os modelos de língua), astral.sh (o uv).
- Ou tente a partir de outra rede (em casa, por exemplo): depois de
  instalado, o cartolex funciona em qualquer rede.

Ao pedir ajuda, envie o arquivo install.log da pasta "cartolex" da sua pasta
pessoal.


Remover o cartolex
------------------

Apague a pasta "cartolex" da sua pasta pessoal e o atalho do cartolex (na
área de trabalho, no menu Iniciar ou no menu de aplicativos). Seus projetos
estão em outro lugar e continuam lá.
